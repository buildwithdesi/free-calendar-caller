What this is

A doorbell for meetings. Not a whole apartment building.

Your calendar already knows what is coming. This bot only rings you for stuff that matters: client calls, interviews, strategy sessions. It speaks what / when / where, then texts the Meet link.

ELI5

Your calendar is a list of playdates. The bot is a parent who only yells when it is time to leave — and texts you the Zoom link so you are not digging through apps.

AI builds the robot. You unlock the doors.
Human vs AI parts
Why NOT Supabase

This is not a Percolator / SaaS app.

Full Digital Alchemy products (login, dashboards, multiple users, saved data) use Supabase + auth + RLS. That is the Percolator stack. This free caller is on purpose simpler.

Skip Supabase here

One person. One phone. A timer that checks every 5 minutes. Adding Supabase is like renting a warehouse to store one lunchbox.

This recipe

GitHub Actions + CallMeBot + Google Calendar. Free. Personal.

Percolator apps

Next.js + Supabase + Clerk + real multi-user product.

ELI5

Supabase is a shared fridge for a whole house. This bot is a sticky note on YOUR fridge. Sticky notes do not need a fridge company.

When Supabase makes sense later

If you want a fancy dashboard, lots of saved overrides, or other people using it — that is a Percolator upgrade. Start free. Graduate when the sticky note is not enough.

YOU do these (human)

Claude cannot click these. Do them once.

1
Human only

Make a clean folder

Desktop → new folder da-edu-html (or any empty name). Point Claude / Codex / Cursor at ONLY that folder. Never your whole Vault or messy Downloads.

ELI5

Empty desk for the AI. Not your whole messy room.

2
Human only

Paste the GitHub link + purple prompt

Copy the prompt below. Paste into Claude or Codex in that clean folder. The AI clones the starter files and wires them.

ELI5

Hand them LEGO instructions. They build. You still put batteries in.

3
Human · Telegram

Allow calls + test CallMeBot

Telegram → Settings → Privacy → Calls → allow. Open CallMeBot browser test page, enter @username, run test. Phone must ring once. If not, stop here.

ELI5

Press the doorbell test until you hear it ring.

4
Human · Google

Calendar API + OAuth client

Google Cloud Console → enable Calendar API → OAuth Web client. Two Gmails? Always pick the account (select_account) or Google reconnects the same inbox twice.

ELI5

Get a permission slip. Pick the right backpack (Gmail) each time.

5
Human · GitHub

Secrets + enable Actions

Repo → Settings → Secrets → Actions. Paste tokens AI tells you. Enable Actions. Run workflow once manually to test.

ELI5

Put secret passwords in the locked drawer. Flip the 15-minute timer switch.

6
Human · ongoing

60-day keepalive

GitHub pauses scheduled workflows after ~60 days of repo silence. Push a tiny commit or re-enable Actions or reminders go silent with zero errors.

ELI5

Nobody visits the workshop, lights turn off. Tap the lights sometimes.

CLAUDE / CODEX
Build me the Free Calendar Caller from this open-source repo: https://github.com/buildwithdesi/free-calendar-caller Do this in THIS clean folder only. Do not touch other projects. Follow the README + starter/ files exactly: 1. Wire CallMeBot voice (soft-fail, check response BODY not just HTTP status) 2. Poll Google Calendar (support 1-2 Gmails with prompt=select_account) 3. Rules + optional overrides for which events ring and minutes-before 4. Idempotent call log so I never get double-called 5. GitHub Actions cron every 5 minutes (starter/.github/workflows/remind.yml) 6. Spoken times must use America/Chicago (or ask me my timezone) 7. Telegram text should include Meet link + location when present Explain every step I (the human) must do myself: CallMeBot one-time auth, Google Cloud OAuth, GitHub Secrets, enabling Actions. Do NOT use Supabase, Clerk, or a full Next.js app unless I ask. This is the free GitHub Actions recipe, not a Percolator/SaaS build.

The pitch

Dumb-simple. Stupid useful.

A bot that watches Google Calendar (up to 2 Gmails), decides what's important, then rings you on Telegram with a voice message (what / when / where). Then it texts the Google Meet link and other calendar crumbs.

No Twilio bill. No "oops I forgot that call" tax.

Important filter

Bouncer list, not fire alarm

  • Keyword rules (client / interview / strategy → ring)
  • Skip junk (all-day, birthdays, Focus Time)
  • Per-rule timing (client 60+15, personal 30)
  • Dashboard override: Call me? + minutes-before
"Lock in. Client strategy call at 3:00 PM Central. Location: Google Meet. Get ready."

Student path

Build this for free

  1. CallMeBot (5 min) — Allow Telegram calls. Authorize once on CallMeBot's browser test page. If the test doesn't ring, stop and fix that first.
  2. Google Calendar — Enable Calendar API + OAuth. Two Gmails? Use prompt=select_account or Google silently re-auths the same login twice.
  3. Drop in starter files — Download the kit below (or copy each file). Wire your refresh tokens in run-once.js.
  4. Cron — Add the workflow, set GitHub Secrets, enable Actions.
  5. Idempotency — Log event_id + window + channel or you get double-called.

Gotchas

Steal these

  • CallMeBot can return HTTP 200 with an error in the body. Read the body.
  • GitHub Actions auto-pauses after ~60 days of inactivity. Keepalive or re-enable.
  • Format times with an explicit timezone (America/Chicago). Runners are UTC.
  • Two Google accounts without select_account = fake dual-calendar setup.
